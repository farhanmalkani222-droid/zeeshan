Implementation Plan & Substitution Map

How to replace the US import, function by function — and the phased plan, capex, team and milestones to build it. Gujarat-local direction: graded kraft-sack fibre + cotton + chemistry.

Prepared 2 Oct 2026 · Capex/team figures are indicative planning estimates — confirm with vendors. Proportions validate on the mill trial.

PRINCIPLE   The US import is not one thing — it delivers four jobs at once: long fibre (RCT), bonding (BF), consistency (grade), and on-tap supply. Substitute each job with an India source. Replace the system, not just a material.

Flexibility is the point: because strength comes from a few graded long-fibre inputs + chemistry, you can swap the cheap base freely with price — the recipe is a dial, not a fixed formula.

2 · The plan — phase by phase

PHASE 0 · 0–2 MONTHS · VALIDATE

Prove the substitution works

  • Buy one US import bale + collect local kraft-sack / cotton / OCC samples.
  • Lab-test the import → write the target spec (fibre length, BF/RCT contribution, cleanliness, moisture).
  • Run the mill trial (Control vs Mix A/B/C) on one associated mill; measure BF, RCT, colour, smell, runnability, ₹/tonne.
✔ Milestone: a passing recipe + proven ₹ saved/tonne. Cost: low (samples + lab + trial time).
PHASE 1 · 2–6 MONTHS · SET UP

Build the Fibre Grading & Blending Unit

  • Lease a shed/warehouse in the Morbi/Vapi/Ahmedabad belt.
  • Install the line: intake, sorting tables/conveyor, de-contamination, moisture control, baler, weighbridge, small QC lab (burst + ring-crush testers).
  • Lock supply contracts for kraft sacks, box trim, cotton waste.
  • File patent/IP on the recipe + grading method; register the grade brand ("India-DLK Grade A").
  • Sign first 5–10 mills on gain-share.
✔ Milestone: unit producing graded bales to spec; first paying mills. Capex: indicative ₹50 L–₹1.5 Cr for a modest unit (confirm with vendors).
PHASE 2 · 6–18 MONTHS · SCALE GUJARAT

Own the belt

  • Roll across the 50 associated mills + Morbi/Vapi cluster.
  • Build a recipe library by BF grade; standardise QC + spec sheets per grade.
  • Scale sorting throughput; add a second shift / baler as volume grows.
  • Formalise gain-share contracts; build the technical-service team.
✔ Milestone: steady recurring volume & margin across dozens of mills.
PHASE 3 · 18 MONTHS+ · PAN-INDIA

Expand the brand

  • Replicate the unit model in other mill clusters (UP-Muzaffarnagar, Punjab).
  • Scale to 500+ mills; position "India-DLK" as a known graded brand.
  • Add a premium tier (toll-pulped cotton/MFC) for top grades as price allows.
✔ Milestone: national graded-fibre brand substituting imports at scale.
